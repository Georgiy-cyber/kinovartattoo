# КИНОВАРЬ — сайт тату-студии

Многостраничный демонстрационный сайт тату-студии в Москве.
Тёмная эстетика, киноварный акцент, крупная антиква, галерея работ.

**Стек:** чистый HTML + CSS + JS. Без сборки, без зависимостей.
Открывается двойным кликом по `index.html`.

## Что уже работает

- Фиксированный хедер со стеклом, затемняется при скролле
- Мобильное меню-бургер, полноэкранное
- Плавный скролл по якорям с учётом высоты хедера
- **Заголовки: буквы поднимаются из-под маски** (split-text, с задержкой по буквам)
- **Фото и карточки открываются шторкой снизу** (clip-path), а не просто fade
- **Курсор-акцент**: кольцо, которое увеличивается над ссылками и кнопками
- **Боковая надпись в hero** (вертикальная типографика)
- Кнопки: прямоугольные, капсом, с заливкой снизу при наведении
- Навигация: точка-маркер под активным пунктом
- Hover на работах: затемнение выезжает шторкой, фото из ч/б в цвет
- Галерея с фильтрами по стилю (страница «Работы»)
- Модалка записи на любой странице, Esc и Tab-фокус
- Валидация формы: имя, телефон с маской +7, согласие
- Экран «Заявка принята»
- Активный пункт меню подсвечивается автоматически
- SEO: canonical, Open Graph, микроразметка TattooParlor, robots, sitemap
- Адаптив: 1180 / 980 / 720 / 520 px
- Поддержка `prefers-reduced-motion`: всё движение отключается
- Без JS контент виден (fallback в `<noscript>`)

## Изображения

Все фото лежат в `assets/img/` с фиксированными именами:

| Файл | Где используется | Формат |
|---|---|---|
| `hero-art.svg` | фон первого экрана — **рисунок**, не фото | SVG, любые размеры |
| `about.jpg` | блок «О студии» | 4:5, 1100×1350 |
| `style-1…6.jpg` | карточки стилей + страница «Стили» | 4:5, 800×1000 |
| `artist-01…04.jpg` | карточки мастеров | 4:5, 800×1000 |
| `work-01…12.jpg` | галерея работ | 3:4, 900×1200 |

**Заменить фото** — положи файл с тем же именем в `assets/img/`. Код менять не нужно.

Сейчас стоят сгенерированные заглушки: тёмные абстракции с киноварным светом.
Они не имитируют татуировки — это честные плейсхолдеры под твои реальные фото.

### Автоматическая подготовка фото (ч/б, размеры, вес)

В проекте есть скрипт `tools/prepare-photos.py`. Он берёт **любые** картинки
из папки `_incoming/` и сам делает всё остальное:

```bash
# ч/б (по умолчанию)
python tools/prepare-photos.py

# ч/б с киноварным тоном
python tools/prepare-photos.py --red

# оставить цвет, только размеры и сжатие
python tools/prepare-photos.py --color
```

Что делает:

1. обрезает по центру (портреты мастеров — с приоритетом верха, чтобы не срезать голову);
2. ресайзит под нужные пропорции: 16:9, 4:5, 3:4;
3. переводит в ч/б с подтянутым контрастом и зерном;
4. сжимает до лимита веса (если не влезает — понижает качество, потом размер);
5. раскладывает по `assets/img/` с правильными именами.

Порядок = алфавитный порядок файлов. Первые два идут на `hero` и `about`,
дальше 6 на стили, 4 на мастеров, 12 на работы. Чтобы управлять —
называй файлы `01.jpg`, `02.jpg`, `03.jpg` и так далее.
